# 今月あといくら？ PWA

## iPhoneでホーム画面に追加する
1. このフォルダ一式をHTTPSで公開します（GitHub Pagesなど）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有 → 「ホーム画面に追加」→ 追加。
4. ホーム画面のアイコンから起動すると、アプリ風の全画面表示になります。

## 機能
- 月予算
- 支出追加・削除
- 自由な支出項目追加
- 今日使える目安
- 予算消化率
- 今日の支出フィルター
- 項目別集計
- 月が変わると支出を自動リセット
- localStorage保存
- オフライン利用用Service Worker
